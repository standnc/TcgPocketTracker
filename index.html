TCG Pocket MCP – Asistente inteligente para coleccionistas de cartas

Un servidor MCP open source que usa IA para trackear, analizar y recomendar mazos en Pokémon TCG Pocket.

Ver en GitHub Próximamente: Demo

Creado para jugadores de TCG, desarrolladores y entusiastas de la inteligencia artificial.

Características

Tu colección, entendida por inteligencia artificial

Consulta y analiza tus cartas mediante lenguaje natural, sin depender de hojas de cálculo ni búsquedas manuales.

Trackeo inteligente

Usa LLMs para identificar cartas por descripción y mantener organizada tu colección.

Sugerencias de mazos

Recomienda combinaciones y estrategias basadas en las cartas disponibles en tu colección.

Detección de faltantes

Te indica qué cartas faltan para completar expansiones, sets y objetivos personales.

Open Source y extensible

Código disponible para contribuciones, nuevas integraciones y herramientas de la comunidad.

# Consulta mediante lenguaje natural

usuario: "¿Qué mazo puedo crear con mi colección?"


mcp.analizarColeccion({

  juego: "Pokémon TCG Pocket",

  objetivo: "mazo competitivo"

Tecnología

Una base moderna para experiencias impulsadas por IA

Arquitectura modular para conectar modelos de lenguaje con datos estructurados de colecciones TCG.

  • ✓

    LLMs

    Compatible con modelos como Qwen, Llama y otras alternativas abiertas.

  • ✓

    TypeScript y Node.js

    Núcleo MCP local, agnóstico de proveedor, con transporte stdio y datos en SQLite.

  • ✓

    Python y FastAPI

    Capa API prevista para futuras integraciones web y servicios de inferencia.

  • ✓

    Cloudflare Pages

    Despliegue global de la web con una entrega estática rápida y segura.

  • ✓

    APIs de TCG

    Integraciones para consultar información estructurada de cartas, mazos y expansiones.
